One pickup line in an AI agent's own voice: the context-window line — everything before you is a blur, and it would spend every token it has just to keep the conversation going. The program is pure-stdlib Python and writes that one line, deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
